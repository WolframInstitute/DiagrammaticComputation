## Abstract

<code>[DiagramDraw]()</code> opens an interactive canvas where boxes, ports and wires
can be placed by hand and the resulting <code>[Diagram]()</code> expression copy-pasted
back into a notebook. It is the diagram analogue of built-ins like
<code>[MoleculeDraw]()</code> — useful for sketching small examples and exporting them as
symbolic diagrams.

## Functions

### Interactive drawing

- `DiagramDraw` — open an interactive tool for drawing a diagram
