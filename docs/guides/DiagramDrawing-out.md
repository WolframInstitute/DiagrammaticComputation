## Abstract

<code>[DiagramDraw](https://resources.wolframcloud.com/PacletRepository/resources/Wolfram/DiagrammaticComputation/ref/DiagramDraw)</code> opens an interactive canvas where boxes, ports and wires can be placed by hand and the resulting <code>[Diagram](https://resources.wolframcloud.com/PacletRepository/resources/Wolfram/DiagrammaticComputation/ref/Diagram)</code> expression copy-pasted back into a notebook. It is the diagram analogue of built-ins like <code>[MoleculeDraw](https://reference.wolfram.com/language/ref/MoleculeDraw.html)</code> — useful for sketching small examples and exporting them as symbolic diagrams.

## Functions

### Interactive drawing

- `DiagramDraw` — open an interactive tool for drawing a diagram
